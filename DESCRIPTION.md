### 🚀 Launch Your AI SaaS Product in Days, Not Months

The **AI SaaS Platform** template gives you everything you need to go from idea to a fully functional, professional-looking AI product — without starting from scratch.

Built with the latest **React 18**, **TypeScript 5**, **Vite 5**, and **TailwindCSS 3**, this template follows industry best practices and is structured for real-world scalability.

### ✨ What's Included

#### 🌐 Marketing Landing Page
- Animated hero section with live code demo card
- Social proof stats bar (Uptime, Response Time, API Calls, Models)
- 9-feature showcase grid with colored icons and hover effects
- 3-tier pricing section (Starter / Pro / Enterprise) with popular badge
- Full-width footer with navigation links
- Responsive navbar with mobile hamburger menu

#### 🔐 Authentication Pages
- User login page
- User registration page (with password confirmation)
- Dedicated admin login page

#### 📊 Admin Dashboard (4 pages)
- **Overview Dashboard** — 4 KPI stat cards + API usage area chart + recent activity table
- **Users Management** — searchable/filterable user table with status badges (Active, Suspended)
- **API Keys** — create, reveal, copy, and revoke API keys with masked display
- **Analytics** — dual charts (usage + cost), model breakdown table (GPT-4, GPT-3.5, DALL-E 3, Claude)

#### 🎨 Design System
- Custom Tailwind color palette (primary blue + accent purple)
- Fully reusable component library: Button, Card, Input, Table, Badge
- Google Fonts (Inter) typography for premium feel
- Smooth CSS transitions, hover states, and micro-animations
- 100% responsive — mobile, tablet, and desktop
